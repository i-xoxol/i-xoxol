# Igor Khokhlov

**Assistant Professor of Cybersecurity · Sacred Heart University**

I work on AI and machine learning in cybersecurity, threats to AI/ML systems, mobile and usable security, and data security and quality. My teaching interests include mobile security, intrusion detection and prevention, and AI/ML in cybersecurity.

This GitHub brings together research simulations, authentication teaching examples, and software projects.

## Selected projects

| Project | Focus |
| --- | --- |
| [G.H.O.S.T. simulation code and data](https://github.com/i-xoxol/GHOST-paper-data) | Python simulations exploring metadata privacy, communication overhead, and token incentives. |
| [Phone Assistant](https://github.com/i-xoxol/phone-assistant) | A self-hosted phone assistant using Twilio, OpenAI, and the Model Context Protocol. |
| [Authentication Module Lab](https://github.com/i-xoxol/AuthModuleLab) | Educational authentication examples in Python and Java, with a Flask API and browser interface. |
| [CY410 authentication example](https://github.com/i-xoxol/TempCY410Auth) | A Python/Flask example covering password hashing, registration, and JWT authentication. |
| [CV website](https://github.com/i-xoxol/cv-website) | A Next.js portfolio and monitoring dashboard. |

Earlier Android projects include [StuffOrganizer](https://github.com/i-xoxol/StuffOrganizer) and [SteekezExchange](https://github.com/i-xoxol/SteekezExchange). Their repositories preserve the original implementations and tooling.
