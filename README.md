# Igor Khokhlov

**Assistant Professor of Cybersecurity · Sacred Heart University**

I work on AI and machine learning in cybersecurity, threats to AI/ML systems, mobile and usable security, and data security and quality. My teaching interests include mobile security, intrusion detection and prevention, and AI/ML in cybersecurity.

This GitHub brings together cybersecurity research, hands-on teaching examples, and self-hosted tools for everyday workflows.
